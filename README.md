# EMGS 中文助手 / EMGS 中文助手

**简体中文**

一个面向中国内地、香港、澳门、台湾留学生的 EMGS 查询界面。用中文查看 EMGS Hub 上已有的申请进度、电子证件、指定诊所、通知与入境体检记录。

> 本项目是独立的第三方界面，非 EMGS 官方网站。EMGS 及相关标志归其权利人所有。

**演示站点：https://zhemgs.hker.dpdns.org**

**作者没有对官方的代码做任何二次更改**：本仓库的全部内容都是作者独立编写的中文查询界面，没有修改、复制或分发 EMGS 官方应用或官方网站的任何代码。页面数据均通过 EMGS 官方接口获取。

**繁體中文**

一個面向中國內地、香港、澳門、台灣留學生的 EMGS 查詢介面。用中文查看 EMGS Hub 上已有的申請進度、電子證件、指定診所、通知與入境體檢記錄。

> 本專案是獨立的第三方介面，非 EMGS 官方網站。EMGS 及相關標誌歸其權利人所有。

**演示站點：https://zhemgs.hker.dpdns.org**

**作者沒有對官方的代碼做任何二次更改**：本倉庫的全部內容都是作者獨立編寫的中文查詢介面，沒有修改、複製或分發 EMGS 官方應用或官方網站的任何代碼。頁面資料均透過 EMGS 官方介面取得。

## 功能 / 功能

**简体中文**

- EMGS 账号登录（支持邮箱验证码两段登录），登录状态保存在本地
- 申请进度环形图、申请历史、个人资料
- 电子 iKAD：证件字段、正反面翻卡、扫码查验二维码
- 入境后签到进度与签到历史（按官方 checkInHistory 计算）
- 合作诊所列表 + 最近诊所定位
- 通知中心（英文内容可自动翻译为简体/繁体）
- 简体 / 繁体切换，界面文案全中文
- 联系作者反馈（一个账号一天一次）
- PWA：可添加到主屏幕，更新自动生效
- 常见问题、条款与支持、隐私与政策页

**繁體中文**

- EMGS 帳號登入（支援電子郵件驗證碼兩段登入），登入狀態保存在本地
- 申請進度環形圖、申請歷史、個人資料
- 電子 iKAD：證件欄位、正反面翻卡、掃碼查驗 QR Code
- 入境後簽到進度與簽到歷史（按官方 checkInHistory 計算）
- 合作診所列表 + 最近診所定位
- 通知中心（英文內容可自動翻譯為簡體/繁體）
- 簡體 / 繁體切換，介面文案全中文
- 聯絡作者回饋（一個帳號一天一次）
- PWA：可加到主畫面，更新自動生效
- 常見問題、條款與支援、隱私與政策頁

## 技术栈 / 技術棧

**简体中文**：Vue 3 + Vite。后端不含在本仓库中：登录与查询需要一个实现 EMGS OAuth 1.0a HMAC-SHA1 签名的转发服务，密码只在登录那一次转交，不在服务器保存。

**繁體中文**：Vue 3 + Vite。後端不含在本倉庫中：登入與查詢需要一個實作 EMGS OAuth 1.0a HMAC-SHA1 簽名的轉發服務，密碼只在登入那一次轉交，不在伺服器保存。

## 开发 / 開發

**简体中文**

```bash
pnpm install
pnpm dev
```

生产构建：

```bash
pnpm exec vite build
```

构建产物在 `dist/`，部署为静态站点即可。`public/sw.js` 的 `BUILD` 常量在每次发布时替换为时间戳，让已安装的主屏幕应用能收到更新。

**繁體中文**

```bash
pnpm install
pnpm dev
```

生產構建：

```bash
pnpm exec vite build
```

構建產物在 `dist/`，部署為靜態站點即可。`public/sw.js` 的 `BUILD` 常數在每次發佈時替換為時間戳，讓已安裝的主畫面應用能收到更新。
